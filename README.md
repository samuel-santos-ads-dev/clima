# 🌤️ Clima

Aplicação web de previsão do tempo que permite consultar as condições climáticas de diferentes cidades por meio da API OpenWeather.

O projeto apresenta informações meteorológicas de maneira simples e intuitiva, utilizando JavaScript para consumir dados externos e atualizar dinamicamente a interface.

## 🚀 Demonstração

Acesse o projeto: [Clima – Previsão do Tempo](https://samuel-santos-ads-dev.github.io/clima/)

## ✨ Funcionalidades

- Pesquisa de condições climáticas por cidade.
- Exibição da temperatura atual.
- Consulta das temperaturas máxima e mínima.
- Descrição das condições climáticas.
- Informações sobre umidade do ar.
- Exibição da velocidade do vento.
- Ícones correspondentes às condições meteorológicas.
- Favicon dinâmico, alternando entre dia e noite.
- Interface adaptada para dispositivos móveis.
- Atualização automática do ano no rodapé.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo.
- **CSS3:** estilização e responsividade.
- **JavaScript:** manipulação do DOM, eventos e consumo de API.
- **OpenWeather API:** obtenção dos dados meteorológicos.
- **Font Awesome:** utilização de ícones.

## ⚙️ Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/samuel-santos-ads-dev/clima.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd clima
   ```

3. Configure sua chave de acesso da OpenWeather API no arquivo `script.js`.

4. Abra o arquivo `index.html` no navegador.

**Observação:** para utilizar a API, é necessário possuir uma chave de acesso da OpenWeather. Como a aplicação utiliza JavaScript no navegador, a chave fica visível no código-fonte. Para uma aplicação pública, recomenda-se utilizar um backend para proteger as credenciais ou aplicar restrições de domínio e limites de utilização à chave.
